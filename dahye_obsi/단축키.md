
* ctrl+p : 명령어 팔레트
	* 다른 폴더로 이동처리 (⭐️단축키 지정)
* ctrl+o : 퀵 스위처 (노트 빨리 찾기)
* ctrl+t : 새 탭 열기
* ctrl+w : 탭 종료
* alt : alt 누른채 여러 폴더/노트 선택
* ctrl+e : 읽기모드로 전환
* 탭 우클릭 + split right/left : 탭 위치 이동
	* 드래그앤드롭도 가능
* 탭 우클릭 + move to new window : 탭을 새로운 창으로 분리
	* 드래그앤드롭도 가능
* 탭 그룹 오른쪽 화살표(아래) + stack tabs : 탭을 스택 형태로 확인
